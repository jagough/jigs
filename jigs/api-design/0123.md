# Resource Types

APIs expose resources that users create, retrieve, and manipulate. Each resource has a type that defines its structure, behavior, and identity. This document describes how to define resource types in OpenAPI specifications and how to annotate C# code to generate proper OpenAPI schemas with resource metadata.

## Guidance

APIs **must** define a resource type for each resource, following the format `{Service Name}/{Type}`. The type name **must**:

- Start with an uppercase letter
- Contain only ASCII alphanumeric characters
- Use PascalCase formatting
- Be the singular form of the noun

### Examples 
- `marketplace.jagough.com/Vendor`
- `marketplace.jagough.com/Products`
- `map.jagough.com/Location`

## Annotating resource types in OpenAPI

Resource types **must** be documented using the `x-resource` extension on schema definitions. Each resource type **must** specify:

- `type`: The resource type identifier
- `pattern`: The canonical resource name pattern (following JIG-122)
- `singular`: The singular form in camelCase
- `plural`: The plural form in camelCase

```yaml
components:
  schemas:
    Vendor:
      type: object
      x-resource:
        type: "marketplace.jagough.com/Vendor"
        pattern: "vendors/{vendor}"
        singular: "vendor"
        plural: "vendors"
      properties:
        name:
          type: string
          description: "Canonical resource name"
          example: "vendors/jonny-mart"
        displayName:
          type: string
          example: "Jonny's Mart"
```

### Resource references

Fields that reference other resources **must** use the `x-resource-reference` extension. The extension **must** contain the resource type identifier of the referenced resource.

```yaml
components:
  schemas:
    Product:
      type: object
      x-resource: 
...
      properties:
        name:
          type: string
          description: "Canonical resource name"
          example: "vendors/jonny-mart/products/widget-42"
        parent:
          type: string
          description: "Resource name of the parent vendor"
          example: "vendors/jonny-mart"
          x-resource-reference: "marketplace.jagough.com/Vendor"
...
```

## .NET Implementation

To generate the `x-resource` and `x-resource-reference` extensions in .NET using Swashbuckle, define custom attributes and a schema filter.

### Attributes

```csharp
[AttributeUsage(AttributeTargets.Class | AttributeTargets.Struct)]
public class ResourceTypeAttribute : Attribute
{
    public string Type { get; init; }
    public string Pattern { get; init; }
    public string Singular { get; init; }
    public string Plural { get; init; }
}

[AttributeUsage(AttributeTargets.Property)]
public class ResourceReferenceAttribute : Attribute
{
    public string ResourceType { get; init; }

    public ResourceReferenceAttribute(string resourceType)
    {
        ResourceType = resourceType;
    }
}
```

### Schema filter

```csharp
using Microsoft.OpenApi.Any;
using Microsoft.OpenApi.Models;
using Swashbuckle.AspNetCore.SwaggerGen;

public class ResourceSchemaFilter : ISchemaFilter
{
    public void Apply(OpenApiSchema schema, SchemaFilterContext context)
    {
        var resourceType = context.Type.GetCustomAttribute<ResourceTypeAttribute>();
        if (resourceType != null)
        {
            schema.Extensions["x-resource"] = new OpenApiObject
            {
                ["type"] = new OpenApiString(resourceType.Type),
                ["pattern"] = new OpenApiString(resourceType.Pattern),
                ["singular"] = new OpenApiString(resourceType.Singular),
                ["plural"] = new OpenApiString(resourceType.Plural)
            };
        }

        foreach (var property in context.Type.GetProperties())
        {
            var reference = property.GetCustomAttribute<ResourceReferenceAttribute>();
            if (reference != null)
            {
                var propName = char.ToLowerInvariant(property.Name[0]) + property.Name[1..];
                if (schema.Properties.TryGetValue(propName, out var propSchema))
                {
                    propSchema.Extensions["x-resource-reference"] =
                        new OpenApiString(reference.ResourceType);
                }
            }
        }
    }
}
```

Register the filter:
```csharp
builder.Services.AddSwaggerGen(options =>
{
    options.SchemaFilter<ResourceSchemaFilter>();
});
```

### Usage

```csharp
[ResourceType(
    Type = "marketplace.jagough.com/Product",
    Pattern = "vendors/{vendor}/products/{product}",
    Singular = "product",
    Plural = "products")]
public record Product(
    string Name,
    [ResourceReference("marketplace.jagough.com/Vendor")] string Parent,
    string Title
);
```
