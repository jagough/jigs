# Standard Methods: Get

The Get method retrieves a single resource by its resource name.

## Guidance

APIs **must** provide a Get method for resources. The Get method returns the current state of a single resource.

### HTTP mapping

- HTTP verb: `GET`
- URI **must** contain a single variable field called `name`
- The `name` field **should** be called `name`
- The URI **should** have a variable corresponding to this field
- The `name` field **must** be the only variable in the URI path
- All remaining parameters **must** map to URI query parameters
- No request body

Example:
```
GET /v1/{name=vendors/*/products/*}
```

### Request

The request **must** include the full resource name in the URL path.

Example:
```
GET /v1/vendors/acme-corp/products/widget-42
```

### Response

The response **must** be the resource itself, fully populated with all fields. The API **should** return a complete representation of the resource.

```yaml
# 200 OK
{
  "name": "vendors/acme-corp/products/widget-42",
  "title": "Super Widget",
  "price": 29.99,
  "create_time": "2024-01-15T10:30:00Z",
  "update_time": "2024-01-20T14:25:00Z"
}
```

## OpenAPI specification

```yaml
paths:
  /v1/{name}:
    get:
      summary: Get a product
      operationId: GetProduct
      parameters:
        - name: name
          in: path
          required: true
          description: "Full resource name in the format: vendors/{vendor}/products/{product}"
          schema:
            type: string
          example: "vendors/acme-corp/products/widget-42"
      responses:
        '200':
          description: Successful response
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Product'
        '404':
          description: Product not found
        '403':
          description: Permission denied
```

## .NET implementation

- The request handler type name **must** begin with "Get" followed by the singular form of the resource name (e.g., `GetProduct` for `Product` resource).
- The request message **must** match the handler type name, with a `Request` suffix (e.g. `GetProductRequest`).
- The request **must** include a `Name` property representing the full resource name. The request **must not** include additional required fields beyond what is needed to construct the resource name.
- The URI should contain a single variable field corresponding to the resource name.
This field should be called name.
The URI should have a variable corresponding to this field.
The name field should be the only variable in the URI path. All remaining parameters should map to URI query parameters.
The response **must** be the resource itself.

**Note**: .NET's routing system does not natively support a single `{name}` path variable containing slashes. The implementation below uses separate path parameters for each segment, then constructs the full resource name.

```csharp
// .../Products/Requests/GetProductRequest.cs
public record GetProductRequest
{
    [FromRoute(Name = "vendorId")]
    public required string VendorId { get; init; }

    [FromRoute(Name = "productId")]
    public required string ProductId { get; init; }

    // The Name field represents the full resource name
    public string Name => $"vendors/{VendorId}/products/{ProductId}";
}

// .../Products/MapEndpoints.cs
public static class MapEndpoints
{
    public static RouteGroupBuilder MapProductEndpoints(this RouteGroupBuilder app)
    {
        var group = app.MapGroup("vendors/{vendorId}/products")
            .WithTags("Products");

        group.MapGet("{productId}", GetProduct.Handle)
            .WithName("GetProduct")
            .WithSummary("Get a product")
            .WithDescription("Retrieve a single product by its ID");

        return group;
    }
}

// .../Products/Endpoints/GetProduct.cs
public static class GetProduct
{
    public static async Task<Results<Ok<Product>, NotFound>> Handle(
        [FromServices] IProductRepository repository,
        [AsParameters] GetProductRequest request,
        CancellationToken cancellationToken)
    {
        // Use the Name property (full resource name) to retrieve the resource
        var product = await repository.GetAsync(request.Name, cancellationToken);

        if (product is null)
        {
            return TypedResults.NotFound();
        }

        // Response must be the fully-populated resource
        return TypedResults.Ok(product);
    }
}
```
